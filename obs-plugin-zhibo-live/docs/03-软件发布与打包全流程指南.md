# 软件发布与打包全流程指南

在产品准备向主播或客户交付时，很多团队都会面临关键疑问：
> **“我该如何发布？是生成一个独立的插件 exe 安装包，还是先在电脑上安装调试好自己的 OBS，然后再整套打包发布？”**

本文档对比业界成熟方案，给出**两种发布模式的深度技术剖析、Inno Setup 自动化打包脚本模板以及全流程发布检查清单**。

---

## 一、 两种发布模式对比与选型建议

| 比较维度 | 模式一：独立插件安装包 (`obs-zhibo-live-setup.exe`) | 模式二：一体化绿色专版客户端 (`智播直播助手-Setup.exe`) |
| :--- | :--- | :--- |
| **核心形式** | 只发布插件自身（DLL + 语言包 + 安装引导） | 包含官方经过测试的 OBS 稳定便携底座 + 预装插件 + 预设好场景与去重滤镜 |
| **安装体积** | 极小（约 5MB ~ 15MB） | 较大（解压后约 200MB ~ 300MB，压缩安装包约 90MB） |
| **用户体验** | 用户电脑必须已自行安装并调好 OBS | **开箱即用**，安装后双击桌面图标即可输入卡密开播 |
| **环境兼容性** | 受制于用户电脑上的 OBS 版本（可能装了过老版本或 32 位） | **100% 绝对兼容**，运行环境 0 差异 |
| **售后支持成本** | 较高（常见问题：找不到 OBS 路径、版本不匹配、主播不会加源） | **极低**（一切环境与参数出厂前已调至最佳状态） |
| **行业标杆参考** | 各种开源第三方插件分发形式 | **斗鱼直播伴侣、虎牙直播助手、快手直播伴侣等商业标配** |
| **推荐适用场景** | 针对专业主播、自带成熟直播工程的高级用户 | **针对公会运营、矩阵开播、非技术主播（强烈推荐！）** |

### 💡 商业落地最佳建议：双轨发版策略
1. **主推【模式二：一体化绿色专版】（覆盖 90% 用户）**：
   直接提供 `智播助手-v1.0.0-Setup.exe`，主播一键安装，桌面双击即用，省去 99% 的远程调试和环境售后成本。
2. **辅推【模式一：独立插件安装包】（覆盖 10% 用户）**：
   提供给明确要求在自己现有 OBS 工程中使用的专业老主播。

## 二、 模式一：独立插件安装器制作指南

### 1. 技术流程
1. 使用 MSVC 编译生成 Release 版本的 `obs-zhibo-live.dll`；
2. 提取 `assets\locale\` 多语言包；
3. 下载微软官方 `VC_redist.x64.exe`；
4. 使用开源著名的 **[Inno Setup](https://jrsoftware.org/isdl.php)** 编写安装脚本，一键编译为单个 `.exe` 安装程序。

### 2. Inno Setup 完整脚本模板 (`installer-plugin-only.iss`)

将以下脚本保存在 `E:\pdk\obs-plugin-zhibo-live\installer.iss`：

```pascal
; =====================================================================
; PDK 智播云控 OBS 插件独立安装程序脚本 (Inno Setup 6+)
; =====================================================================

#define MyAppName "智播云控 OBS 拉流插件"
#define MyAppVersion "1.0.0"
#define MyAppPublisher "PDK"
#define MyAppURL "https://pdk.graddu.com"
#define PluginDllPath "build\Release\obs-zhibo-live.dll"

[Setup]
AppId={{D37F89B2-2C9A-4E38-A98B-7F126938BA01}
AppName={#MyAppName}
AppVersion={#MyAppVersion}
AppPublisher={#MyAppPublisher}
AppPublisherURL={#MyAppURL}
DefaultDirName={code:GetDefaultObsPath}
DirExistsWarning=no
DisableDirPage=no
OutputBaseFilename=智播云控-OBS拉流插件-v{#MyAppVersion}-Setup
Compression=lzma2/ultra64
SolidCompression=yes
ArchitecturesInstallIn64BitMode=x64
ArchitecturesAllowed=x64
PrivilegesRequired=admin
WizardStyle=modern

[Languages]
Name: "chinesesimp"; MessagesFile: "compiler:Default.isl"

[Files]
; 1. 插件核心 DLL
Source: "{#PluginDllPath}"; DestDir: "{app}\obs-plugins\64bit"; Flags: ignoreversion restartreplace
; 2. 多语言包
Source: "assets\locale\*"; DestDir: "{app}\data\obs-plugins\obs-zhibo-live\locale"; Flags: ignoreversion recursesubdirs createallsubdirs
; 3. (可选) 微软 VC++ 2015-2022 x64 运行库
; Source: "redist\VC_redist.x64.exe"; DestDir: "{tmp}"; Flags: deleteafterinstall

[Run]
; 静默安装 VC++ 运行库 (如果本地未安装)
; Filename: "{tmp}\VC_redist.x64.exe"; Parameters: "/install /quiet /norestart"; Flags: runhidden waituntilterminated

[Code]
// 自动从注册表探测 OBS Studio 64位安装目录
function GetDefaultObsPath(Param: string): string;
var
  InstallPath: string;
begin
  if RegQueryStringValue(HKLM64, 'SOFTWARE\OBS Studio', '', InstallPath) then
  begin
    Result := InstallPath;
  end
  else if RegQueryStringValue(HKLM32, 'SOFTWARE\OBS Studio', '', InstallPath) then
  begin
    Result := InstallPath;
  end
  else
  begin
    Result := 'C:\Program Files\obs-studio';
  end;
end;

// 安装前检查 OBS 是否正在运行
function InitializeSetup(): Boolean;
var
  ErrorCode: Integer;
begin
  Result := True;
  // 通过 tasklist 检查 obs64.exe 是否正在运行
  if Exec('cmd.exe', '/c tasklist /FI "IMAGENAME eq obs64.exe" | findstr /I "obs64.exe"', '', SW_HIDE, ewWaitUntilTerminated, ErrorCode) then
  begin
    if ErrorCode = 0 then
    begin
      MsgBox('检测到 OBS Studio 正在运行中！' #13#10 #13#10 '为了确保插件成功安装，请先保存并关闭 OBS，然后再继续安装。', mbConfirmation, MB_OK);
    end;
  end;
end;
```

## 三、 模式二：一体化绿色专版制作指南（商业推荐）

> **“在电脑上安装好自己的 OBS，安装并调试好插件、场景、滤镜，然后再打包发布”** —— 这正是当前各大直播服务商最核心的做法。

### 1. 为什么必须开启 OBS 便携模式 (Portable Mode)？
普通安装的 OBS，其场景文件和插件配置默认保存在当前 Windows 用户的 `%APPDATA%\obs-studio` 目录下。直接拷走安装目录会导致换一台电脑后配置丢失！
* **解决办法**：在 OBS 根目录下创建一个名为 **`portable_mode.txt`** 的空文件；
* **神奇效果**：一旦存在该标记，OBS 的所有全局配置、插件配置、场景预设都会**严格保存在当前 OBS 目录下的 `config\` 文件夹中**，彻底实现绿色便携化！

### 2. 制作步骤图解

```text
步骤 1: 下载官方绿色包 -> 步骤 2: 开启便携模式 -> 步骤 3: 部署智播插件 -> 步骤 4: 调优场景与滤镜 -> 步骤 5: Inno 一键打包
(OBS 30.2.3 便携版)    (portable_mode.txt)     (DLL + 语言包)       (预建拉流源与滤镜)      (生成单文件 Setup.exe)
```

#### 具体操作流程：
1. **获取官方纯净便携底座**：
   * 从 OBS 官网或 GitHub Release 下载 `obs-studio-30.2.3-Windows.zip` 并解压，例如解压至 `D:\ZhiboOBS_Package`；
2. **开启便携模式**：
   * 在 `D:\ZhiboOBS_Package` 根目录新建文本文件，重命名为 **`portable_mode.txt`**；
3. **部署智播云控插件**：
   * 将 `build\Release\obs-zhibo-live.dll` 拷贝至 `D:\ZhiboOBS_Package\obs-plugins\64bit\`；
   * 将语言包拷贝至 `D:\ZhiboOBS_Package\data\obs-plugins\obs-zhibo-live\locale\`；
4. **统一预设与场景调优**：
   * 双击运行 `D:\ZhiboOBS_Package\bin\64bit\obs64.exe`；
   * 设置通用参数：输出分辨率 1080p、帧率 60fps、视频码率 6000kbps、音频采样率 48kHz；
   * 检查场景集合：确保主场景中已经存在“智播拉流源”，并且已附加好画面和音频去重变异滤镜；
   * 关闭 OBS（配置已自动保存进 `D:\ZhiboOBS_Package\config\`）；
5. **Inno Setup 封装打包**：
   * 使用 Inno Setup 将 `D:\ZhiboOBS_Package` 整套目录封装为 `智播直播助手-v1.0.0-Setup.exe`；
   * 设置安装时自动在桌面和开始菜单创建指向 `bin\64bit\obs64.exe` 的快捷方式（图标可换为智播定制图标）。

## 四、 正式发布检查清单 (Release Checklist)

每次向客户或运营团队发布安装包前，执行以下自检：

- [ ] **1. 编译模式检查**：
  - 确认构建使用的是 **Release** 配置（`PDK_RELEASE_BUILD`），绝不可将带有本地 `127.0.0.1:8080` 的 Debug 版打包流出。
- [ ] **2. ABI 结构体尺寸验证**：
  - 确认 `struct obs_source_info` 保持为 **408 字节**，在标准 OBS 30 下右键来源可以正常呼出“渠道去重滤镜”。
- [ ] **3. 接口域名解析检查**：
  - 确认打包机能正常解析并访问 `https://pdk.graddu.com` 及 RTMP 端口 `1935`。
- [ ] **4. 权限与杀软防报毒处理**：
  - 若条件允许，对生成的 `.exe` 与 `obs-zhibo-live.dll` 使用企业代码签名证书（DigiCert / GlobalSign）进行数字签名；未签名时，在发布群或文档中提前提示用户将安装目录加入信任名单。
- [ ] **5. 干净机器脱机测试**：
  - 在一台从未安装过开发环境（无 VS2022、无 Qt）的纯净 Windows 10/11 虚拟机或测试机上执行安装，验证是否能一次性正常启动、激活与拉流播放。
