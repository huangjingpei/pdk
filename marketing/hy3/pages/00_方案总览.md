## 一、品牌定位

- **品牌名**：PDK 商业授权中台（英文占位 PDK License Hub）
- **核心定位**：面向软件厂商 / 独立开发者 / 渠道商的可私有化「商业授权与订阅管理」中台
- **一句话主张**：让每一份授权，都清晰可控
- **价值支柱**：多业务隔离 · 设备许可与卡密分发 · 套餐订阅 · 客户端安全接入 · 私有化部署 · 二次开发定制

## 四、合规声明（重要，请发布前逐页核对）

1. **禁用广告法绝对化用语**：不出现「最 / 第一 / 唯一 / 顶级 / 首选 / 全网 / 最佳 / 国家级」等。
2. **不承诺收益或效果**：不出现「月入 / 稳赚 / 包过 / guaranteed」等。
3. **不涉及灰产内容**：不出现任何第三方平台的风控规避、数据抓取、逆向工程、养号防封等表述——这类内容在小红书 / 视频号均属违规，也触碰平台规则。本方案全部锚定在「授权管理中台 + 二次开发技术服务」的合法定位。
4. **案例与数据泛化**：客户案例用「某直播工具厂商 / 某 SaaS 团队」等泛称，不编造真实名称与具体数字，必要时标注「示意」。
5. **引导用语克制**：用「了解 / 预约演示 / 关注」，避免「私信免费送 / 加微信领资料」等过度诱导。
